# Kana Typing Practice Web App

This interactive web application helps users practice typing Japanese Hiragana characters. It displays a Romaji prompt, and the user types the corresponding Hiragana character into an input field using their keyboard and IME. The app provides immediate feedback and cycles through various characters, reinforcing learning through active keyboard input, as advocated by the article.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in your web browser.
3. Ensure your operating system has a Japanese IME (Input Method Editor) enabled to type Hiragana.
